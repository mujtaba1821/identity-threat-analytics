About the data. Synthetic, generated for this project: 8,536 sign-ins from 107 accounts over 30 days, with benign noise built to trip naive rules (business travel, a Frankfurt VPN exit, mobile carrier geolocation, a password-expiry day, a helpdesk lockout, a legacy SMTP printer, an employee back from leave) and six labeled attack scenarios. Precision is measured on this data; real environments are noisier.

All IPs are from reserved ranges (RFC 5737, RFC 2544, RFC 6598). Code, data and rules: Python generator, detection engine, evaluation and exports are in the project repository.
